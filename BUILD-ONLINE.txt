PisoTab v0.6 — Windows Portable Build

This build kit avoids the local Windows .bat build. The included GitHub Actions workflow builds the Windows x64 portable EXE on a Windows runner.

Steps:
1. Create a new GitHub repository.
2. Upload all files and folders from this folder into the repository. Keep the .github/workflows/build-windows-portable.yml file.
3. Open the repository's Actions tab.
4. Select "Build PisoTab Windows Portable".
5. Click "Run workflow".
6. Wait for the build to finish.
7. Open the completed workflow run and download the artifact named "PisoTab-Portable-v0.6.0".
8. Extract the downloaded artifact. It contains PisoTab-Portable-0.6.0.exe.

The target PC does not need Node.js installed. The portable EXE bundles the Node 22.23.2 runtime and PisoTab server.
